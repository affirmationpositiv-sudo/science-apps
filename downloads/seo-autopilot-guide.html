1. GitHub Pages SEO Grundlagen

GitHub Pages ist von Haus aus SEO-freundlich, aber mit diesen Optimierungen erreichst du Top-Rankings.

2. Automatische Sitemap-Generierung

Erstelle eine sitemap.xml mit allen Seiten deiner GitHub Pages Site:

#!/bin/bash
echo '<?xml version="1.0" encoding="UTF-8"?>'
echo '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">'
find . -name "*.html" | while read f; do
  echo "  <url><loc>https://USER.github.io/REPO/$f</loc></url>"
done
echo '</urlset>'

3. Meta-Tags Optimization

Jede Seite braucht optimierte Meta-Tags:

<meta name="description" content="Deine 150-Zeichen Beschreibung mit Keywords">
<meta property="og:title" content="Titel fur Social Media">
<meta property="og:description" content="Beschreibung fur Social Media">

4. Keyword-Recherche (Kostenlos)

Nutze diese kostenlosen Tools:

  • Google Search Console (kostenlos)
  • AnswerThePublic.com
  • Ubersuggest (Neil Patel)
  • Google Trends

5. Automatische Indexierung

Reiche deine Sitemap bei Google ein:

curl "https://www.google.com/ping?sitemap=https://USER.github.io/REPO/sitemap.xml"

6. Performance-Optimierung

  • Bilder komprimieren (WebP-Format)
  • CSS/JS minifizieren
  • Lazy Loading fur Bilder
  • CDN-Caching (automatisch bei GitHub Pages)

7. Backlink-Strategie

  • GitHub-Profil mit Link zur Page
  • Reddit-Posts mit naturlichem Link
  • DEV.to Cross-Posting
  • StackOverflow-Antworten mit Referenz

8. Monitoring & Tracking
