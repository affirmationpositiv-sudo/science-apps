Chat mit jedem Modell

OpenAI, OpenRouter, vLLM, Ollama, llama.cpp — ein Interface für alle. Du entscheidest, welches Modell läuft.

KI-Agenten

Gib ihm Tools (Shell, Web, Dateien, MCP) und es erledigt ganze Aufgaben selbstständig.

🔬

Deep Research

Mehrstufige Recherchen — Quellen sammeln, analysieren, zusammenfassen. Mit visuellem Report.

📚

Cookbook

Scannt deine Hardware, empfiehlt passende Modelle. Download & Serve per Klick.

E-Mail & Kalender

Dokumente & Notizen

Multi-Tab Editor mit KI-Assistenz. Notes mit Remindern und geplanten Tasks.

Mobile-first

🔒

Privacy-first

Alles lokal. Deine Daten verlassen nie deinen Rechner.

Theme-Editor

🖥️ Selbst hosten — in 3 Minuten

Voraussetzung: Python 3.11+, Docker (optional)

git clone https://github.com/pewdiepie-archdaemon/odysseus.git
cd odysseus
cp .env.example .env
docker compose up -d --build

Oder nativ auf macOS:

./start-macos.sh

Öffne http://localhost:7860 — fertig.
