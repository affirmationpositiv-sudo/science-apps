Selbstgehostete KI 2026: Dein eigener KI-Workspace in 3 Minuten

Juni 2026 · Lesezeit: 3 Min.

Du willst eine KI, die DIR gehört. Kein Abo. Keine Cloud. Keine Daten, die irgendwo in Kalifornien liegen.

Odysseus ist genau das: Ein selbstgehosteter KI-Workspace — Open Source, privacy-first, und gratis.

Was Odysseus alles kann

Mehr als nur Chat:

💬 Chat mit jedem Modell — OpenAI, OpenRouter, Ollama, vLLM, llama.cpp. Du wählst.
🤖 KI-Agenten — mit Tools wie Shell, Web, Dateien, MCP
🔬 Deep Research — mehrstufige Recherchen mit Quellen
📧 E-Mail + Kalender — IMAP/SMTP mit KI-Triage, CalDAV
📝 Dokumente + Notizen — Editor mit KI-Assistenz
📱 Mobile-first — läuft perfekt auf dem Handy (PWA)

In 3 Minuten installiert

git clone https://github.com/pewdiepie-archdaemon/odysseus.git
cd odysseus
cp .env.example .env
docker compose up -d --build

Oder nativ auf macOS:

./start-macos.sh

Öffne http://localhost:7860 — fertig.

💡 Tipp: Mit OpenRouter bekommst du 200+ Modelle — viele davon komplett gratis. Kein API-Key? Kein Problem. Odysseus läuft auch komplett offline mit lokalen Modellen via Ollama.

Warum selbst hosten?

• Privacy — deine Daten verlassen nie deinen Rechner
• Kostenlos — kein Monatsabo, keine Limits
• Kontrolle — du bestimmst, welche Modelle laufen
• Open Source — kein Vendor-Lock-in, keine Blackbox
